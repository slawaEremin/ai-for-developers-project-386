# Календарь звонков

Сервис, в котором гости выбирают время для звонка с владельцем календаря.

## Терминология

**Владелец**:
Человек, с которым гости бронируют встречи. У календаря один владелец.

**Гость**:
Человек, который выбирает тип встречи и записывается на звонок без регистрации.
_Избегать_: клиент, зарегистрированный пользователь.

**Тип встречи**:
Вариант встречи с заданными названием, описанием и длительностью, например «Консультация» на 30 минут.
_Избегать_: тип звонка.

**Слот**:
Свободный интервал для встречи выбранного типа. Его длительность совпадает с длительностью этого типа встречи.

**Запись**:
Подтверждённая встреча гостя с владельцем в выбранное время.
_Избегать_: заявка.
