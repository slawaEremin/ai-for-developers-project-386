# Фронтенд

Vue 3, TypeScript в строгом режиме и Vite. Нужны Node.js 24.22.2 из корневого `.nvmrc` и npm 10.8.2 из `packageManager` корневого `package.json`. Зависимости входят в корневой npm workspace и закреплены общим `package-lock.json`.

Из корня репозитория выполните `make setup`, затем запустите Vite.

```sh
npm run dev --workspace apps/frontend
```

Главная страница доступна по адресу `http://127.0.0.1:5173/`. Она рассказывает
о сервисе и будущем процессе записи: выбор типа встречи, свободного времени
и подтверждение. Иллюстрация календаря помечена как пример и не интерактивна.

Кнопки записи ведут на `http://127.0.0.1:5173/#/booking` — заглушку
«Запись на звонок скоро появится» со ссылкой на главную. Гостевая запись пока недоступна. Главная и заглушка не требуют API.

Ссылка «Владельцу» открывает `/#/owner` без входа и регистрации. Форма
создаёт тип встречи через сгенерированный SDK и POST `/api/meeting-types`.
Обязательны id, название, описание и длительность 1–540 минут. Проверка
выполняется при отправке, ошибки обновляются при исправлении. Во время
запроса форма заблокирована; ошибка сохраняет ввод, успех очищает форму
и показывает ссылку на созданный тип. При потере ответа предлагается
проверить каталог; автоматического повтора нет. Каталог добавляется
следующей задачей. Черновик после ухода со страницы не сохраняется.
Для формы нужны запущенные PostgreSQL и бэкенд; Vite проксирует `/api`
на `http://127.0.0.1:8000`. Интерфейс адаптирован для телефона.

Для страниц используется навигация по hash без дополнительного роутера.
Такие ссылки можно открывать напрямую и перезагружать при раздаче файлов
через FastAPI без серверного перенаправления на `index.html`.
При смене страницы обновляются заголовок вкладки и фокус на заголовке страницы.

```sh
npm run lint --workspace apps/frontend
npm run test --workspace apps/frontend
npm run build
```

Тесты Vitest монтируют корневой компонент в DOM через Vue Test Utils и проверяют
описание сервиса, предупреждение о недоступности записи и навигацию между страницами.
Линтинг включает ESLint и проверку типов `vue-tsc`. Сборка сохраняется в `apps/frontend/dist`.

Из корня репозитория доступны `make test` для тестов обоих приложений и `make build` для сборки фронтенда. Единая команда `make check` последовательно запускает линтинг, проверку генерации, тесты и сборку; она же выполняется в GitHub Actions на каждый push.

SDK в `src/api/generated` генерируется командой `make generate` и используется формой владельца. Генерация SDK и установка зависимостей выполняются из корня репозитория.
