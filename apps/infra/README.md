# Инфраструктура

Один Docker-образ содержит FastAPI и собранный Vue. Контекст сборки находится в корне репозитория.

```sh
docker build -f apps/infra/Dockerfile -t calendar .
docker run --rm -p 8000:8000 calendar
```

Главная страница доступна по адресу `http://127.0.0.1:8000/`, заглушка записи —
`http://127.0.0.1:8000/#/booking`, API — `http://127.0.0.1:8000/health`,
документация — `http://127.0.0.1:8000/docs`.

Сборка устанавливает закреплённые npm и Python зависимости, генерирует OpenAPI, модели Python и SDK, затем собирает Vue. Итоговый образ содержит только Python, зависимости исполнения, код бэкенда и готовые статические файлы. Приложение запускается от непривилегированного пользователя на порту 8000.

Для сборки нужны работающий Docker daemon и доступ к реестрам образов и пакетов. База данных и Docker Compose на этом этапе не используются.
