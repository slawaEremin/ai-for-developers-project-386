# Метки triage

Навыки используют пять канонических ролей. Назначай соответствующую
метку из таблицы.

| Роль навыка | Метка в GitHub Issues | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Требует первичной оценки сопровождающим |
| `needs-info` | `needs-info` | Ожидает дополнительных сведений от автора |
| `ready-for-agent` | `ready-for-agent` | Полностью описана, готова к выполнению агентом |
| `ready-for-human` | `ready-for-human` | Требует реализации человеком |
| `wontfix` | `wontfix` | Выполняться не будет |

При изменении словаря обновляй столбец «Метка в GitHub Issues».
